# Некоторые заметки — обновление v4 → v9

Это обновление предназначено для `Kefirtshik83/math-library`, проверенного на 10 ноября 2026 года.
В репозитории обнаружена старая версия генератора и редактора (v4) с добавленным `--mathjax`.

## Установка

1. Распакуйте архив на компьютер.
2. Откройте репозиторий GitHub → Add file → Upload files.
3. Перетащите **содержимое распакованного архива**, а не сам ZIP.
4. Проверьте, что пути сохранены: `assets/editor.js`, `assets/site.js`, `assets/styles.css`, `build.py`, `collections.json`, `notes/seminar-9-nilpotent-groups.md`, `README.md`.
5. Нажмите Commit changes и дождитесь успешного GitHub Actions.
6. Откройте https://kefirtshik83.github.io/math-library/ и при необходимости сделайте Ctrl+Shift+R.

- `build.py` — генерация каталога и отдельных страниц разделов; сохранение сворачиваемых доказательств при переходе от старой разметки.

- `assets/site.js` — управление боковыми панелями и оглавлением.
- `assets/styles.css` — оформление, мобильный и планшетный интерфейсы.
- `notes/seminar-9-nilpotent-groups.md` — пустая статья «Seminar 9 — Nilpotent groups» в математических заметках.
- `README.md` — эти инструкции.

## Что НЕ меняется

**Этот архив не содержит `notes/coarse-group-cohomology.md`.** Ваш математический текст и ваши правки не будут перезаписаны при загрузке файлов архива.
Не требуется заново загружать `.github/workflows/pages.yml`, PDF, MathJax или уже сгенерированные HTML-страницы: GitHub Actions соберёт их из исходников.
Локальные черновики сохраняются в хранилище текущего браузера, не в репозитории.

## Известные ограничения

- Редактор использует Markdown с формулами LaTeX, не полноценную LaTeX-компиляцию.
- Кнопки создания и редактирования работают с локальными черновиками, но публикация через веб-редактор требует отдельной авторизации GitHub (токен): не вставляйте секреты в публичный репозиторий.
- Автоматическая сквозная нумерация ссылок на теоремы между статьями ещё не реализована.
- Для старой статьи сворачиваемые панели будут восстановлены автоматически во время сборки; исходный Markdown при этом не меняется.
